Dao-Shell 0.1.0 — Windows 桌面试用版

适用 Windows 10/11 x64。双击安装包，安装后从桌面或开始菜单打开 Dao-Shell。
无需安装 Rust、Node.js 或打开命令行。安装包包含小型 WebView2 安装引导程序；
已有运行环境时会直接复用，缺少时需要联网从微软下载安装完整运行环境。
缺少 WebView2 且无法联网时，请先安装微软提供的 WebView2 离线运行环境。

界面默认跟随 Windows 用户界面语言：中文系统显示简体中文，其余显示英文。
可在“设置 → 通用与外观 → 界面语言”选择跟随系统 / 简体中文 / English，保存后生效并跨重启保留。
已有会话文字、文件路径和应用名称不翻译；新的模型回复默认遵循界面语言，用户明示其他语言时优先。

先看看“概览”。如需使用自然语言，在左下“设置 → 模型”选择
DeepSeek / OpenAI / 自定义，输入自己的 API Key，测试连接并保存。
在“设置 → 访问”中选择完全访问（默认使用匹配的全盘索引组件），或受限访问并添加允许目录。也可以先用文件名搜索，不配置模型。
自然语言请求会把相关文件名称、路径和元数据发给你选择的模型服务。
本版本不随包提供 API Key；模型服务可能产生费用。

本轮体验：内存显示百分比和已用/总量；CPU、内存榜同时展示。
点击当前搜索候选直接使用 Windows 默认应用打开（包含 HTML、EXE）；无需再次确认。
结束进程/应用仍需明确确认，可能丢失未保存内容；无法核验或受保护的进程不操作。
完全访问时默认使用匹配的全盘索引组件；首次保存完全访问会提示明确安装/更新，普通启动和搜索不自动提权。

另一台电脑卷更新持续失败时，可在设置→文件搜索生成并复制安全诊断报告；不含私人文件路径或账户标识。
