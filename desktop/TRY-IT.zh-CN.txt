Dao-Shell 0.1.0 — Windows 桌面试用版

适用 Windows 10/11 x64。双击安装包，安装后从桌面或开始菜单打开 Dao-Shell。
无需安装 Rust、Node.js 或打开命令行。安装包包含 WebView2 离线安装组件；
已有运行环境时会直接复用。首次安装缺少该组件时可能需要稍等。

先看看“我的电脑”。如需使用自然语言，在左下“设置 → 模型”选择
DeepSeek / OpenAI / 自定义，输入自己的 API Key，测试连接并保存。
在“设置 → 访问”中选择允许搜索的目录。也可以先用文件名搜索，不配置模型。
自然语言请求会把相关文件名称、路径和元数据发给你选择的模型服务。
本版本不随包提供 API Key；模型服务可能产生费用。

这是未签名的早期试用包，Windows 可能显示“未知发布者”或信誉提示。
请核对来源；不要关闭系统安全防护。当前不提供自动更新。
卸载可使用 Windows 的“已安装的应用”。卸载保留个人配置与已保存凭据，
不会删除你搜索的文件。
