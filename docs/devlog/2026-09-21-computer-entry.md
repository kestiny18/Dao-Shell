# 从文件窗口，到能了解电脑的小入口

这次把代码评审中的六个方向落到同一条使用路径：打开主页了解电脑状态，
在设置里连好模型并选择访问范围，再通过自然语言找到文件并确认打开。

主页直接读取本地 CPU、内存、磁盘、基本设备信息、网络接口计数器和 Windows
卸载注册表记录，不自动联系模型。应用记录不等于所有应用，IP 配置也不等于联网成功。
点击解释按钮才会把这次资源快照和前五个进程事实送给模型，应用清单不随之发送。

设置页借鉴 Noval 的分类与表单方式，保留 Dao-Shell 的主页、文件、设置三个入口。
模型连接与模型名称分开存储，支持多个连接和默认选择；已保存的密钥不回传界面。
模式切换、模型更换与保存只发生在请求之间，保存后清空旧候选并开始新会话。

安全模式沿用目录白名单。完全访问允许指定当前用户能访问的本机位置，但不提升
系统权限、不免除确认、也不增加删除或覆盖等能力。默认搜索位置与访问权限分开，
因此选择完全访问不会立即扫描全盘。桌面仍只有文件查找、元数据和确认打开；
CLI 移动保留已有的持久记录和文件身份核对。

核心执行移到 `runtime.rs`，请求互斥、取消和一次性确认放在共享控制层。
只读会话不再创建临时 Journal。Provider 配置、传输、诊断和设置服务分开，
旧 CLI 配置继续读取；`cli/mod.rs` 改为 `cli.rs`。

本地验证：66 项根包测试、1 项桌面桥接测试和 3 项 DOM 行为测试通过，另有
1 项 CPU 负载测试默认忽略。真实本机概览采样通过，未在日志输出应用或进程清单。
新主页与设置页的原生视觉复验遇到 Windows 锁屏，仍待完成；DOM 测试不替代这一项。
