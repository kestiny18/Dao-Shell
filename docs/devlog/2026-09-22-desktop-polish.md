# 让桌面入口更容易使用

这轮围绕实际试用反馈改进五处细节：

- 沿用已有绿色 D 与箭头图形，明确配置桌面应用的 PNG / Windows ICO 打包资源。
- 设置入口移到左侧底部，让主页与文件留在主要导航区域。
- 左右分栏可拖动调宽，保留内容区域最小宽度；方向键也能调整，双击恢复默认。
- 已登记应用默认用卡片展示，可切换列表并筛选。能读取本机图标时显示图标，否则显示名称缩写。显示方式和侧栏宽度会记住。
- 模型配置改为“DeepSeek / OpenAI / 自定义 → 模型 → API Key”。官方地址自动填入；自定义服务显示地址输入，本机模型也走这里。服务备注和环境变量放入更多设置。

之前的服务下拉框存在一个错误的 HTML 结束标签，导致 DeepSeek 选项没有正常出现。这次修复了标签，并对三个服务选项、切换后的默认模型以及密钥清空补了行为回归。

内置模型是少量快捷选项，不是完整模型目录，也不表示每个账号都有权限。保留“其他模型 / 多个模型”输入。模型名核对来源：[DeepSeek 模型列表](https://api-docs.deepseek.com/api/list-models/)、[OpenAI GPT-5 Mini](https://developers.openai.com/api/docs/models/gpt-5-mini)、[GPT-4.1](https://developers.openai.com/api/docs/models/gpt-4.1)。

图标读取仅处理本地固定磁盘上的 EXE / DLL / ICO 资源，拒绝网络地址、设备路径和重解析点，不执行应用。每次概览只尝试有限数量的图标，并在批次间检查时间预算；不可用时不影响应用名称展示。图标和应用清单不随资源解释发给模型。

分发仍是开发预览：这轮配置了图标资源，没有新增安装器或发布稳定版。
