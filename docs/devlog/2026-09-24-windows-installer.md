# 让朋友不用打开终端就能试用

此前试用桌面入口需要拉取代码、准备开发环境，再运行脚本。这轮增加一个 Windows
x64 的 `.exe` 安装包：安装后从开始菜单打开窗口，配置自己的模型即可使用。
程序以 Windows GUI 子系统构建，启动不会创建命令行窗口。

安装包沿用绿色 D 与箭头图标，提供简体中文和英文安装界面，默认安装到当前用户
目录下的 `Programs/Dao-Shell`。配置仍保留在原来的 `Dao-Shell` 数据目录。
包内包含 WebView2 离线安装组件、许可证及中文试用说明，因此约 212 MiB。
已有 WebView2 的电脑会复用现有运行环境。

依赖检查发现当前 GNU 构建还需要 `WebView2Loader.dll`。只打入 WebView2 运行环境
并不足够；打包脚本现在先构建程序，再补齐这个 DLL，最后生成安装包。
它来自构建依赖，Microsoft 签名有效，安装后的程序已确认从安装目录加载它。

本机验证：静默安装和卸载均返回成功；开始菜单快捷方式正常生成和移除；
安装版在仅包含 Windows 系统目录的 PATH 下启动，辅助功能文档显示主页及本机概览。
PE 检查确认安装版为 x64、GUI 子系统；直接子进程只有 WebView2。
卸载前后的用户配置哈希一致，示例文件保留。再次安装也成功，保留供本机试用。
五项 DOM 回归检查通过。

验证有明确边界：当时 Windows 已锁屏，无法完成安装向导和文件搜索的点击式验收；
也尚未在另一台没有开发环境、没有 WebView2 的电脑上验证。包内没有真实模型密钥，
本轮没有调用付费模型。安装包未签名，Windows 可能提示未知发布者；当前没有自动更新。

安装文件：`dist/Dao-Shell-0.1.0-windows-x64-setup.exe`，221,988,691 字节。
SHA-256：`1f30b6ef9be36be5e68019b86365000bf6380ecde24adae1bb984f453a4be51f`。
