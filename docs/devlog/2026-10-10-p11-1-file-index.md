## 实现决定

文件身份由 backend + stable volume identity + native ID 组成；Windows identity 使用卷 GUID + serial，检查点含 Journal ID/USN，仅后端解释。名称表允许同一 FRN 对应多个 parent/name，目录移动后按父身份重新解析后代。根目录身份从系统句柄取得，不用固定 slot 猜测根身份。

首次 MFT 得到 ID 后，以 OpenFileById 读取必要元数据，检查链接数；多链接使用 FindFirstFileNameW / FindNextFileNameW 完整列出名称，再解析父身份。单文件 FSCTL_READ_FILE_USN_DATA 使用 4 KiB 缓冲，不为每条文件分配 MFT 的 1 MiB 页面。变化事件按身份重新协调当前名称集合，不将单个 USN 名称直接当作全文件名称集合。

当前这是正确性基线，首次建库仍有逐文件打开成本，不能声称已达到全盘 30 秒目标。更快方案可探索按目录批量获取 file ID / 标准信息以定位多链接候选，或经单独验证的 MFT 元数据解析；两者都需要新证据，不能以漏硬链接换速度。本任务未新增 raw MFT parser。

明确不存在的完整 FRN 返回 Deleted；OpenFileById 的 87 不能直接作为已删除证据。只有当前 source 曾成功读取的普通文件历史或 USN 删除 reason，再加单页定点 MFT 核对缺失，才接受 Deleted；缺少证据或核对权限不足返回 Unavailable 并保留原因。权限/共享拒绝返回 Unavailable；未知记录版本失败并回滚。缺失父链按完整 FRN 补查，失败保留覆盖缺口，不把 slot 11/29 猜作应排除系统项。任何循环、缺父节点、深度超过 256 的路径不构造虚假结果。不可解析时可以保留有明确 `complete=false` 的代次，不将它标作完整覆盖。

枚举/协调预算耗尽、取消、日志缺口、未知 USN 版本和数据库错误不提交新代次。旧代次及 checkpoint 保留。当前 schema 版本为 2，包含 unavailable 原因与 coverage_reasons。旧 P9/P10、早期 P11 schema 1 或非本应用数据库拒绝打开，不做自动迁移。探针 Build/Replay 的失败报告保留 metrics，`result.published=false` 且进程退出码非零，避免自动化误判成功。

## 本轮实机诊断与最小修复

主 Agent 的提权诊断产物 `1AD66383DADE4B18256823CAF1CEDE474D2EF8AFD24B6120912D154A066F64D6`：slot 11 真实补查成功，指向完整根 FRN；3 个虚构硬链接路径的名称关联均匹配，名称数均为 3；仅 slot 29 的 FSCTL_READ_FILE_USN_DATA 返回 87。详见主 Agent 的本地 `.tools/p11-20261011/inspect-diagnostic.json`，报告只含身份/计数。

先以普通权限分别在 C: tempfile 和 E: 独立 `.tools` tempfile 复现核心 API，再对主 Agent 的 3 个保留夹具路径只读核对，全部关联匹配；真实路径/ID 的临时诊断代码已移除，没有改动保留夹具。

最终修复在单文件 USN 接口返回已知不支持错误（1/50/87）时，改用 GetFinalPathNameByHandleW + 父目录身份，重新打开所得路径且不跟随最后 reparse 点，复核文件完整 ID 和卷 serial；仍不支持则明确 Unavailable，禁止猜系统项名称或硬编码过滤 slot。此 fallback 的句柄/名称/父身份 helper 已以普通权限真实夹具验证；slot 29 最终结果已由主 Agent 运行上述最终产物验证通过，见下。

生命周期测试同时发现 OpenFileById 在删除最后链接后返回 87，区别于 slot 29 的 FSCTL 阶段 87。删除二次核对最多读取一页 MFT，使用低 48 位槽号作为起点，检查完整 FRN 含序列号，并核对卷身份及 Journal ID；未知 MFT 版本和身份变化报错。MFT 缺失不能单独证明所有系统节点已删除，因此还要求先前普通文件成功读取历史或 USN 删除 reason；无证据/无权限保留覆盖缺口。

Inspect 现在保留每个 ID 的成功/失败结果与阶段错误；部分失败也返回非零退出码，不因一个系统节点失败丢掉已成功的夹具断言。

Microsoft 依据：[单文件 USN 版本默认值](https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ns-winioctl-read_file_usn_data)、[OpenFileById 的卷提示句柄](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-openfilebyid)。普通元数据 hint 的实验不改变实际 MFT/USN 卷读取所需权限，也不代表用户正文访问获批。


最终提权检查（主 Agent 提供并可复核的 `.tools/p11-20261011/inspect-final.json`）：冻结产物 `B05486D9EB3ABB0ABC6F542E6AB0AD195D817105C33EB41FC3FBE50831AFBC7D` 返回 `status=ok`；slot 11 为真实目录，父为根；slot 29 经 fallback 成功获得真实目录记录，父为 slot 11；三个虚构硬链接路径 `name_association_matches=true`，每次返回 3 个名称。8 次元数据查找合计 5582 微秒，fallback 1 次，unavailable 0。计时只涵盖这些定点查找，不代表整卷初始化或桌面搜索性能。
