# Experiments

[Documentation](../README.en.md) · [中文导航](../README.md) · [Plans](../plans/README.md)

These are dated explorations, not an instruction to run a scan, elevate permissions, migrate data or replace the current product backend. Keep fixtures isolated and read each experiment's scope before running it.

- [File inventory](file-inventory.md): directory snapshots, notifications, reconciliation and their limits.
- [NTFS volume index](ntfs-volume-index.md): full-volume discovery/USN feasibility and Windows permission findings.
- [Desktop entry](desktop-entry.md): the initial in-process file-session adapter and entry-specific boundaries.

Current implementation and unfinished evidence are tracked in [P11](../plans/2026-10-10-p11-windows-index-service.md), [P12](../plans/2026-10-14-p12-installed-trial-feedback.md) and [P13](../plans/2026-10-15-p13-desktop-bilingual.md). Experimental examples and fixtures remain in the repository; they are not automatically exposed as model tools.
