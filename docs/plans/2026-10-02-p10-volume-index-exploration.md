## Goal / correction

原始产品目标是类似 Everything 的默认全盘文件名/路径索引，不要求逐目录登记。P9 READY 只证明目录级桌面闭环，不代表全盘目标完成；其目录遍历和通知机制作为兼容后端保留。此次优先验证本机 NTFS 卷级方案，不继续以常用目录替代全盘目标。

## Scope / boundaries

- 先选择本机 E: NTFS 卷，以实际卷规模做只读 MFT 枚举和 USN 读取；检测卷类型与身份，不假定所有磁盘都为 NTFS。
- 普通权限与专用提升权限探测分开记录。只允许实验程序读取文件系统元数据，不提升 UI/模型，不安装服务、不绕过 UAC、不读正文、不创建/删除/调整 USN Journal。
- 全卷索引可能含私人文件名与路径，仅写本机 `.tools` 下专用实验目录，不向模型输出完整列表，不上传，不入库。持久报告只包含计数、性能、错误和虚构夹具信息。
- 新增/改名/删除只发生于任务专用临时夹具。真实卷上日志缺口/ID变化使用合成状态验证，不删除真实日志制造故障。
- 本轮不接入桌面生产路径，不自动启动长期后台进程。若权限仍阻塞，必须给出准确失败阶段和已准备好的专用程序，不将单次拒绝访问判成路线不可行。

## Tasks / acceptance

### T1 — 卷级建库及权限验证

- 独立 example/脚本检查 token、卷类型、卷身份、日志 ID/有效范围；按步骤记录 open/query/enum/read 的错误。
- 使用 Windows 卷级接口枚举 MFT 文件记录，保存文件引用号/父引用号/名称等必要元数据；恢复路径并明确未解析项、硬链接、重解析点及未知记录版本的覆盖限制。
- 全卷实际测量记录数、耗时、内存和数据库大小，区分枚举与可查询索引完成时间。不能把枚举第一页视为全盘完成。
- 首次建库衔接期间变化有明确处理，日志中断/缺口不发布为完整索引。

### T2 — 增量、离线补读与恢复

- 保存卷身份、Journal ID、下一条 USN；索引变更与游标原子提交。
- 在任务夹具测试新增、修改、删除、文件和父目录改名，查询可反映变化；重新启动进程补读离线变化，不靠完整重扫掩盖未实现的续读。
- 合成测试覆盖日志 ID 改变、游标过期、非法/未知记录、事务失败；检测后明确需要重建，不静默漏更新。
- 记录事件到可查询延迟、重启补读时间、罕见/无命中查询时间。声明仅实测卷和权限组合有效。

### T3 — 结论与产品路线

- 区分已验证、未验证、被权限阻塞；给出是否可以用 MFT 初始化 + USN 续读替换全量遍历/五分钟重扫的证据。
- 提出职责受限的索引辅助进程/服务边界，普通权限 UI/模型不继承索引权限；确认文件名可见范围与文件操作权限需分别设计。
- 明确非 NTFS、可移动/离线卷、网络盘及日志缺口的兼容路径，不把 NTFS 单卷实验称为全部系统支持。
