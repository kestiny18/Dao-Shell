## 修复

- 普通文件打开、CLI 直接打开、桌面候选打开及旧概览 run/admin/location/appsfeatures 共用固定内部 handoff。CLI/桌面在读取配置和启动 UI 前识别内部模式；协议最长 64 KiB，动作闭集，不接受参数字符串或任意 URL。
- 父进程不修改全局环境。助手使用 CreateEnvironmentBlock(inherit=false) 重建环境，排除 DAO_/TAURI_/WEBVIEW2_ 和所有配置的 api_key_env（大小写不敏感，包括持久用户环境）。父/子进程都复核并持有目标身份，保留 Windows 普通打开及关联语义。ShellExecuteEx 的 NOASYNC 确保短期助手退出前完成派发。
- 取消/90 秒超时后只终止助手，打开结果保持未知，不声称目标应用已停止；同一模型轮次禁止再次打开。显式 UAC 取消保留 cancelled。
- 电脑概览解释复用单次无工具 explain_observation，只发送当前白名单摘要；不携带先前文件结果，拒绝模型工具响应。
